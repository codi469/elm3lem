# إدارة مطعم المعلم

لوحة الإدارة موجودة داخل `elma3lam/admin/`. يمكن فتحها محليًا أو نشرها في هذا المسار، ومعها أصول الصور اللازمة للمعاينة. لا يوجد رابط لها في واجهة الموقع العامة.

ابدأ من تبويب المنتجات أو محتوى الصفحات أو الهوية والمظهر. التعديلات تبقى في الصفحة المفتوحة إلى أن تصدّر ملف `content.js`. لا تغلق الصفحة قبل تصدير التغييرات. لاستكمال تحرير نسخة موجودة، استخدم «استيراد ملف الموقع» واختر ملف `content.js` من مجلد الموقع.

بعد التصدير، استبدل `elma3lam/content.js` بالملف الجديد وانشر الموقع. الصور التي ترفعها تُصغّر وتُضمّن داخل الملف، لذلك قد يكبر حجمه مع كثرة الصور.

عند استضافتها تحت `/admin/` تصبح الصفحة قابلة للزيارة العامة بالرابط المباشر. GitHub Pages لا يوفّر قاعدة بيانات أو مصادقة إدارية لهذه الأداة؛ هي لا تحفظ على الخادم، بل تصدر ملفًا محليًا. لتقييد زيارتها فعليًا فعّل مصادقة على مستوى الخادم أو بوابة وصول موثوقة. لا ترفع أسرارًا أو كلمات مرور داخل ملفات الواجهة.
