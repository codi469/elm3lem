# موقع مطعم المعلم

## الموقع العام
انشر محتويات هذا المجلد على GitHub Pages؛ الصفحة الرئيسية هي `index.html`. ملفات الموقع ثابتة ولا تتطلب تثبيتًا. قائمة الطعام والنصوص والإعدادات والصور المخصصة محفوظة في `content.js`.

## تحديث المحتوى
استخدم لوحة الإدارة الموجودة في `admin/index.html`. صدّر منها `content.js` ثم استبدل هذا المجلد بنسخة الملف التي صدّرتها، وراجع التغيير قبل نشره. مجلد الإدارة موجود تحت `/admin/` ولا يوجد رابط له في واجهة الزوار.

## الصور
صور قسم المطعم تعرض الصورة الأولى في الهاتف، والصورة الثانية في الشاشات الكبيرة. لوحة الإدارة تتيح استبدال البانر والشعار وأيقونة المتصفح وصور القسم والصور الفردية للمنتجات. الصور الجديدة تُضغط داخل ملف المحتوى.

## لوحة الإدارة على الاستضافة

إذا نشرت مجلد `admin` داخل هذا الموقع فسيكون مسار اللوحة `/admin/` ويمكن الوصول إليه مباشرة. اللوحة لا تكتب على ملفات الخادم ولا تملك قاعدة بيانات أو تسجيل دخول؛ المستخدم يصدّر `content.js` ثم يرفعه بنفسه. لا تعتمد على إخفاء المسار لحماية وظيفة إدارية. لتقييد الدخول فعليًا استخدم حماية دخول على الخادم أو بوابة موثوقة مثل حماية الاستضافة قبل تمكين التحرير عبر الإنترنت.

## الطلبات
السلة تستخدم متصفح الزائر وتُرسل الطلب عبر واتساب. لا يوجد دفع إلكتروني أو سجل طلبات أو قاعدة بيانات في هذا الموقع الثابت.
